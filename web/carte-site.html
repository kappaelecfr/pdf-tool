PDF Tool

Éditeur PDF gratuit, pour Windows

Tout se passe sur votre ordinateur : aucun envoi, aucun compte, aucune connexion. Vos documents ne quittent jamais votre machine.

  • Fusionner, découper, tourner et réorganiser les pages
  • Filigrane, numérotation, signature ou tampon
  • Modifier le texte directement dans le PDF
  • Extraire texte, tableaux, images — et OCR pour les scans
  • Interface en 10 langues, dont le français
