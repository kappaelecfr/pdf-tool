PDF Tool — краткое руководство
==========================================================

Редактор PDF, который работает на вашем компьютере. Без интернета,
без учётной записи. Ни один файл не покидает эту машину.


КАК ОТКРЫТЬ ФАЙЛ — три способа
------------------------------
  * кнопка «Открыть PDF» слева вверху
  * перетащите PDF прямо в окно
  * перетащите PDF на значок «PDF Tool.exe»


ЧЕТЫРЕ ВКЛАДКИ СПРАВА
---------------------
  Страницы   объединение, разделение, поворот, удаление, порядок.
             Страницы выбираются нажатием на миниатюры слева, или
             впишите диапазон:  1-3, 7, 10-

  Добавить   водяной знак, нумерация, а также изображение, подпись
             или штамп, который ставится нажатием

  Правка     изменение текста внутри PDF, поиск и замена, а также
             окончательное вымарывание

  Извлечь    текст, таблицы в .csv, изображения, страницы в PNG,
             OCR и сжатие


ПРАВКА ТЕКСТА — ПРОЧТИТЕ ЭТО
----------------------------
PDF не хранит редактируемый текст, как Word. Текст нарисован в
фиксированных местах страницы.

Что делает программа: она закрывает старый текст цветом фона (который
определяет сама) и пишет поверх новый текст, похожим шрифтом и того же
размера.

  Хорошо подходит для   дат, имён, сумм, коротких слов
  Не предназначено для  переписывания целых абзацев — соседние
                        строки не переверстываются

Нажмите «Включить режим правки»: все области текста на странице станут
синими, и вы увидите, на что именно можно нажать. Нажмите на одну,
измените её в поле справа и нажмите «Применить изменение». Ctrl+Z
отменяет что угодно.


МАСШТАБ И ПЕРЕМЕЩЕНИЕ
---------------------
Под страницей: кнопки  -  и  +  , текущий процент и «Вписать», которая
возвращает страницу к размеру окна.

  Ctrl + колесо      увеличение и уменьшение
  колесо             прокрутка вверх и вниз
  Shift + колесо     прокрутка влево и вправо
  перетаскивание     двигает увеличенную страницу


ЯЗЫК
----
Список справа вверху. Интерфейс меняется сразу, без закрытия
документа, и ваш выбор запоминается.


OCR — ДЛЯ ОТСКАНИРОВАННЫХ ДОКУМЕНТОВ
------------------------------------
Если PDF — это скан (фотография бумаги), текст нельзя выделить. OCR
читает буквы прямо с изображения.

Кнопки OCR остаются серыми, пока не установлен Tesseract. Он
бесплатный:

  1. Скачайте установщик для Windows отсюда:
     https://github.com/UB-Mannheim/tesseract/wiki
  2. Запустите его. На шаге с языками («Additional language data»)
     отметьте нужные языки.
  3. Оставьте папку по умолчанию.
  4. Закройте и снова откройте PDF Tool. Кнопки включатся сами.

Всё остальное прекрасно работает и без Tesseract.


КЛАВИАТУРА
----------
  Ctrl+O   открыть         Ctrl+Z   отменить
  Ctrl+S   сохранить       Ctrl+Y   вернуть
  Ctrl+Shift+S  сохранить как   Ctrl+A  выделить все страницы
  Delete   удалить выделенные страницы
  Page Up / Page Down      предыдущая / следующая страница
  Escape   выйти из режима правки или размещения изображения

  Shift+нажатие на миниатюру выделяет весь диапазон.


БЕЗОПАСНОСТЬ
------------
Когда вы сохраняете поверх исходного файла, рядом остаётся резервная
копия с .bak в имени. Если что-то пойдёт не так, уберите «.bak» из
имени — и исходный файл снова у вас.

«Скрыть навсегда» действительно убирает текст из файла. После
сохранения пути назад нет.
