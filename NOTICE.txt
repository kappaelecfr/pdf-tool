FONTS
=====

PDF Tool does not embed or distribute any font. When it writes text
containing accented or Cyrillic letters, it reads a font already
installed on your own Windows system (normally Arial) and embeds only
the individual glyphs used, into your own PDF file. For plain ASCII
text it uses the standard PDF base fonts, which are not embedded at
all.
